## Standard Onboarding Steps

New vendors go through a 4-step onboarding process: (1) procurement intake form, (2) security questionnaire review by the security team, (3) contract and MSA signature, (4) provisioning of any system access the vendor integration requires. The full process typically takes 2-3 weeks, with the security questionnaire review being the most common bottleneck.
